# 当前版本 v1.1

已支持普通消息通知与回访问卷。版本 1.0 源码归档及恢复说明见 [releases/README.md](releases/README.md)，通用任务设计与正式后台边界见 [docs/general-tasks.md](docs/general-tasks.md)。以下早期说明如有差异，以 v1.1 文档为准。

# 信达 · 消息中心
投资者适当性回访问卷的可交互前端原型，React + Vite。

## 运行
```sh
npm install
npm run dev
```
浏览器访问 http://127.0.0.1:5173 。构建 `npm run build`，规则测试 `npm test`。

## 已实现
- 任务列表、状态/日期/名称筛选、详情、终止与新建任务。
- 新建时目标人默认全部，Push / 弹窗配置及预览，CSV/TXT UID 导入、目标类型选择。
- 补发只处理未提交个人客户，每批次按用户生成载体，复用原业务消息和基线快照。
- 结果录入、异常复核、只读操作流水、附件本地保存与下载。
- 用户问卷预览、一次提交、已完成回显、基线及答案快照。
- 按任务、批次、产品风险和客户风险的完成统计、运营效果。
- 筛选结果导出为真实 XLSX，综合报表含三个工作表。
- 响应式导航、表格横向滚动、空态、表单校验和本地持久化。

## 原型边界
全部数据为虚构演示数据，操作仅保存在浏览器 localStorage，没有真实消息下发。问卷题目为示例，需替换正式版本。未连接认证、友盟、服务器、真实人群、定时任务调度、文件上传及异步导出服务。附件最多 1 MB / 文件，本地存储容量由浏览器限制。真实系统需要后端保障事务、唯一约束、权限与审计不可篡改；本地原型不可替代这些约束。

业务冲突决策与视觉设计记录见 docs/design.md。
